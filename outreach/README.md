## Жёсткие правила аутрича
- Только персонально: каждое первое сообщение ссылается на конкретный ролик или факт бренда.
- Нейрокомментинг в Telegram — да, по правилам из `tools-stack.md` (отдельные аккаунты, польза, без фейковых отзывов).
- Массовые одинаковые рассылки в директ — нет: первое сообщение всегда персональное.
- Лимит ручного аутрича в Instagram: ~20–30 новых диалогов в день с одного аккаунта (ориентир рынка, чтобы не ловить ограничения).
- Не называем клиентов Syneps и их цифры. Не выдумываем результаты.
- Не отбираем по расе, национальности, религии.
