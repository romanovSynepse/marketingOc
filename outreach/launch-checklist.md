# Запуск 3 каналов: пошагово

Отмечаем ✅ по мере выполнения. Делаем по одному шагу.

## 0. Общая база (нужна всем каналам)
- [ ] 0.1 Ссылка на календарь для записи на 15-минутное демо (Calendly / Cal.com / Яндекс Календарь — что уже есть)
- [ ] 0.2 Проверить сайт: есть ли оффер «покажем, что залетает в вашей нише» и кнопка записи → если нет, делаем посадочную страницу
- [ ] 0.3 КП на 1 страницу (`kp.md`) → PDF, отправляем только после «интересно, пришлите»
- [ ] 0.4 Список первых 100 бьюти-брендов с ЛПР (собирает Claude)

## 1. Автоаутрич в Telegram (LIDORA)
- [ ] 1.1 Регистрация на lidora.tech → скриншот кабинета
- [ ] 1.2 Созвон с LIDORA: аккаунты свои или их? что при бане? своя база? передача в CRM?
- [ ] 1.3 Аккаунты: 3–5 корпоративных SIM → Telegram, фото, имя, описание, Premium
- [ ] 1.4 Прогрев аккаунтов 1–2 недели (по правилам LIDORA)
- [ ] 1.5 Загрузить базу (сегменты B и D из CRM + новые бренды)
- [ ] 1.6 Вставить первое сообщение и инструкции ИИ-продавцу (пишет Claude)
- [ ] 1.7 Тест на 100 контактов → смотрим ответы → масштаб

## 2. Email-рассылки (Gradly / Coldy)
- [ ] 2.1 Купить отдельный домен под рассылки (reg.ru или другой регистратор)
- [ ] 2.2 Подключить почту на домен (Яндекс 360 для бизнеса), 3 ящика: имена реальных людей команды
- [ ] 2.3 Настроить SPF, DKIM, DMARC (Claude даст записи под регистратор)
- [ ] 2.4 Прогрев ящиков 2–3 недели (встроенный в сервис — проверить)
- [ ] 2.5 Регистрация в Gradly и/или Coldy, подключить ящики
- [ ] 2.6 Загрузить базу, цепочка из 3 писем (пишет Claude)
- [ ] 2.7 Тест на 200 писем → открытия, ответы → масштаб

- [ ] 3.4 Аккаунт в Директе (direct.yandex.ru), реквизиты ИП/ООО
