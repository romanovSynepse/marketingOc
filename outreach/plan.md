# Дорожная карта outreach

## Этап 1. Ручной аутрич по шаблонам (сейчас, 2 недели)
Цель — понять, какой заход и какая ниша отвечают. Без автоматизации.
1. Собрать 100 брендов бьюти/косметики СНГ в `leads-template.csv` (vidIQ: профиль + 12 последних рилсов).
2. Прогнать через квалификатор (`icp-qualifier.md`), взять в работу горячих и тёплых.
3. Для каждого найти 1 вирусный ролик в их нише (vidIQ outliers) — это «подарок» в первом сообщении.
4. Писать с двух аккаунтов по 20–30 диалогов в день, дожимы по графику из `scripts.md`.
5. Считать воронку: отправлено → ответили → «демо» → созвон → сделка.

**Ориентир рынка для холодного персонального директа:** ответ 10–20%, из ответивших в созвон 15–25%.
Свои цифры заменят ориентир после первых 100 сообщений.

## Этап 2. Автоответы на кодовые слова (параллельно)
- Кодовые слова под рилсами и в Telegram → бот (ManyChat / BotHelp / SaleBot) по сценариям `autoreplies.md`.
- У каждого источника своё слово или `t.me/bot?start=<источник>` — чтобы видеть, откуда лид.

## Этап 3. Квалификатор как код
- Скрипт: ник бренда → данные (vidIQ / HikerAPI) → баллы по `icp-qualifier.md` → строка в Supabase.
- Claude пишет черновик первого сообщения с конкретным роликом; человек проверяет и отправляет сам.

## Этап 4. ИИ-продавец
- Отвечает во входящих за 1–5 минут: сначала на вопрос, потом шаг (раздел 19).
- Знает вилку цены, даёт вирусные ролики из ниши клиента, предлагает 2 слота на созвон.
- Передаёт человеку: «готов платить», сложный вопрос, недовольство.
- Метрика успеха: доля «демо» → созвон ≥ 33% (ориентир воронки Syneps).
