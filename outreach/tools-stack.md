## 2. Чего не берём и почему 🔴
| Сервис / функция | Причина |
|---|---|
| 3SELLER, Botseller AI («рой ИИ-аккаунтов» в чатах) | Пока не берём: дублируют GramGPT. Вернёмся, если он перестанет давать лиды |
| Rapport с купленными аккаунтами | Купленные аккаунты = обман и баны. Со своими аккаунтами и ручным ведением — 🟡 можно |
| AIGAM: авторассылка и «перехват клиентов конкурентов» | Массовая рассылка без согласия; мониторинг заявок — можно |
| MindThread-расширение, ClientFlow (автокомменты через браузер) | Неофициальный доступ, риск ограничений, по сути автокомменты под чужими постами |
| Скрипты с GitHub для Threads без API | Неофициальный доступ |
| Sandcastles | Не лидген, конкурент Syneps |

## 2а. Правила нейрокомментинга (решение Ника: канал оставляем)
Цель — чтобы канал жил долго и не бил по бренду.
1. **Отдельные аккаунты.** Не личный аккаунт Ника и не основной Syneps. Прогрев 1–2 недели, рост лимита постепенно.
2. **Комментарий — польза по теме поста:** мысль, совет, разбор. Не «круто, подпишись».
3. **Без фейковых отзывов:** не пишем «я клиент, мне помогло» и выдуманные результаты — это уже обман, а не маркетинг.
4. **Без ссылки в каждом комментарии:** ведём в профиль; в профиле — кодовое слово или `t.me/bot?start=neuro_<канал>`.
5. **Не называем клиентов Syneps.** Каналы конкурентов Syneps — только если там аудитория брендов, без нападок.
6. **Метрики:** комментарии → переходы в профиль → кодовое слово → демо → созвон; плюс баны и удалённые комментарии на 100 комментариев.
7. **Стоп-сигнал:** баны > 20% аккаунтов в неделю или жалобы админов каналов — снижаем частоту и меняем тексты.
