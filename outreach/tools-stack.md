# Агент по привлечению лидов: из каких сервисов собираем

Принцип Syneps: **данные и каналы покупаем, мозг (отбор, тексты, диалог, цикл) держим у себя.**
Цены — с сайтов и из обзоров (ноябрь 2026), сверять на звонке.
Светофор: 🟢 легитимно — берём · 🟡 можно с лимитами и личными сообщениями · 🔴 не берём (баны, спам, граница Syneps).

## 2. Чего не берём и почему 🔴
| Сервис / функция | Причина |
|---|---|
| Нейрокомментинг: Telegram Expert, Neirogram, CommentBot, Telegram Prime | Автокомменты с чужих/купленных аккаунтов — серый канал, баны, спам. Граница Syneps |
| 3SELLER (нейрокомментинг), Botseller AI («рой ИИ-аккаунтов» в чатах) | То же: массовые фейковые аккаунты |
| Rapport с купленными аккаунтами | Купленные аккаунты = обман и баны. Со своими аккаунтами и ручным ведением — 🟡 можно |
| AIGAM: авторассылка и «перехват клиентов конкурентов» | Массовая рассылка без согласия; мониторинг заявок — можно |
| MindThread-расширение, ClientFlow (автокомменты через браузер) | Неофициальный доступ, риск ограничений, по сути автокомменты под чужими постами |
| Скрипты с GitHub для Threads без API | Неофициальный доступ |
| Sandcastles | Не лидген, конкурент Syneps |
| GramGPT | Уточнить механику: если это нейрокомментинг/рассылки с пользовательских аккаунтов — 🔴, если ИИ-ответы на входящие — 🟢 |
