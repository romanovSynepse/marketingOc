# ТЗ: SynOC Outreach — свой автоаутрич с ИИ-продавцом

**Что делает:** находит бренды и ЛПР → квалифицирует → пишет первое персональное сообщение →
ИИ ведёт диалог до демо → все лиды и воронка в одном дашборде.
Образец механики: LIDORA (аутрич + ИИ-квалификатор + ИИ-продавец, ~35 первых касаний в сутки на аккаунт).
Наше отличие: в первом сообщении — подарок из SynOC (вирусные ролики из ниши бренда), а не шаблон.
*We market Syneps with Syneps.*

## 1. Модули

### 1.1 Поиск (источники лидов)
| Источник | Что берём | Как |
|---|---|---|
| Instagram-бренды бьюти | ник, подписчики, рилсы, ссылка в профиле | vidIQ / HikerAPI (не прямые запросы к IG) |
| Сайт бренда | почта, Telegram, имя основателя/маркетолога | парсинг страниц «Контакты», «О нас» |
| Базы компаний | ЛПР, почта, телефон, ИНН | DealRocket / Контур.Компас / Trigga (API или выгрузка) |
| Telegram-чаты (тёплые) | люди, которые сами ищут маркетолога/контент | ФайндЛид / LeadRadar или свой мониторинг по фразам |
| Входящие | кодовые слова РИЛС, НИША, ДЕМО, ЗАВОД, СИСТЕМА | бот (см. `autoreplies.md`) |

Дубли склеиваем по домену сайта и нику Instagram.

### 1.2 Квалификатор (ИИ-агент №1)
- Баллы 0–100 по `icp-qualifier.md` (автоматически из собранных данных).
- Claude дописывает: «боль» бренда одной фразой + какой ролик-подарок подходит.
- Сегменты: горячий / тёплый / холодный / стоп (клиент, конкурент, накрутка).

### 1.3 Первое касание
- Claude пишет персональное сообщение по `scripts.md`: деталь из их ролика + ссылка на вирусный ролик ниши.
- Каналы по приоритету: **email** (свои домены, прогрев) → **Telegram** → директ Instagram (вручную).
- **Режим «человек подтверждает»** первые 2 недели: Ник/менеджер жмёт «Отправить» в дашборде. Потом — автоотправка для сегментов, где ответов много, а жалоб нет.
- Лимиты на аккаунт в сутки: Telegram ≤ 30–35 новых, email ≤ 30–50 с ящика (ориентир рынка).
- Не больше 3 касаний, в каждом письме — «если неактуально, напишите — не буду писать».

### 1.4 ИИ-продавец (ИИ-агент №2)
- Подключается, когда человек ответил. Отвечает за 1–5 минут.
- Правила раздела 19: сначала ответ на вопрос, потом шаг; цена — вилкой $1200–2000; кейсы — роликами из ниши; на созвон — 2 слота из календаря.
- Передаёт человеку: «готов платить», торг, сложный вопрос, раздражение, просьба не писать (→ стоп-лист навсегда).
- Не придумывает цифры и клиентов.

### 1.5 Дашборд
Встраиваем в существующую админку `marketing-summary-table-main/` (React + Python + Postgres) новой вкладкой «Outreach».
- **Воронка:** найдено → квалифицировано → написали → ответили → демо → созвон → сделка, с конверсией каждого шага.
- **Таблица лидов:** фильтры по сегменту, нише, каналу, статусу; карточка лида с перепиской и баллами.
- **Очередь на подтверждение:** черновики первых сообщений — «Отправить / Исправить / Пропустить».
- **Горячие:** кому нужен человек прямо сейчас.
- **Здоровье аккаунтов:** отправлено сегодня / лимит, ответы, жалобы, ограничения.
- **Эффективность заходов:** какой вариант первого сообщения и какой ролик-подарок дают больше ответов.

## 2. Данные (Postgres)
- `companies` — бренд, ниша, сайт, Instagram, подписчики, метрики рилсов
- `contacts` — ЛПР: имя, роль, email, telegram, источник
- `qualifications` — баллы, сегмент, боль, ролик-подарок, дата
- `messages` — канал, аккаунт-отправитель, текст, направление, статус, вариант захода
- `deals` — этап воронки, слот созвона, сумма, причина отказа
- `sender_accounts` — аккаунт, канал, лимит, отправлено сегодня, состояние
- `stop_list` — кто попросил не писать, клиенты, конкуренты

## 3. Этапы
| Этап | Что готово | Срок (оценка) |
|---|---|---|
| MVP-1 | Поиск по Instagram + квалификатор + черновики сообщений в дашборде; отправка вручную | 1–2 недели |
| MVP-2 | Email-отправка с прогревом + ИИ-продавец на ответы + календарь | +2 недели |
| MVP-3 | Telegram-канал, тёплые заявки из чатов, автоотправка для лучших сегментов | +2–3 недели |
| Дальше | США: email (Instantly/Smartlead-подобная логика) + Threads-бот | — |

## 4. Риски и как их закрываем
- **Холодные сообщения в Telegram:** правила Telegram запрещают спам — жалобы = бан аккаунта.
  В РФ рекламные рассылки без согласия — нарушение закона «О рекламе» (ст. 18), штрафы.
  → Пишем только ЛПР компаний, лично по делу, с лимитами, с отпиской; основной холодный канал — email; аккаунты Ника не используем для холодных.
- **Нейрокомментинг, инвайтинг, массовые авторассылки — не делаем** (жёсткая граница Syneps).
- **Персональные данные:** храним только рабочие контакты из открытых источников; удаляем по просьбе.
- **Сторонние сервисы (LIDORA и др.):** грузим только списки лидов, данные клиентов Syneps — никогда.
