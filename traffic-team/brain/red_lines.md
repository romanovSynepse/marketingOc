# Красные линии

Основано на «Роадмапе выхода на глобал» (раздел «Красные линии для США») и правилах платформ.
Агенты не генерируют контент и действия, нарушающие эти пункты.

## Контент
- **Клонирование = рерайт уровня 2–3.** Берём паттерн (хук, структура, механика удержания, триггер, оффер)
  и пишем НОВУЮ единицу под Syneps. Рерайт уровня 1 (та же единица, слегка изменённая) не делаем:
  с апреля 2026 Instagram не рекомендует новой аудитории аккаунты, которые в основном постят чужой
  или не переработанный контент. Из нескольких одинаковых роликов платформа продвигает только оригинал.
- Не копируем текст чужих постов дословно. Цитаты — только короткие, с указанием автора.
- AI-аватары и AI-голос — только с раскрытием (пометка AI). Нельзя выдавать их за реальных
  покупателей или независимых экспертов (FTC, Meta).
- Цифры — только подтверждённые кейсами из product.md. «Опыт сотен проектов», «в 5–8 раз дешевле»
  и подобное — только со ссылкой на кейс.
- Логотипы брендов из white-label пилотов не упоминаем без письменного разрешения.

## Дистрибуция
- Публикация только через официальные API на собственные аккаунты Ника и Syneps.
- Никаких ферм аккаунтов, сеток прогретых аккаунтов, уникализаторов метаданных и обхода детекции дублей.
- Автокомменты: только ответы на комментарии под СВОИМИ постами и comment-to-DM по кодовому слову
  (официально через Instagram API / ManyChat). Массовые комментарии под чужими постами не делаем,
  это спам по правилам платформ.
- Два аккаунта в Threads допустимы, если оба реальные и прозрачные (личный + бренд), без накрутки друг друга.

## Аутрич
- Только персонализированные сообщения, разумный объём (до 30–50 в день с одного ящика).
- В email: реальный отправитель, физический адрес, ссылка на отписку (CAN-SPAM, GDPR для ЕС).
- Не покупаем базы с персональными данными. Собираем публичные бизнес-контакты.
