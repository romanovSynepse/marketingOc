## Воронка и оцифровка
Каждая активность получает UTM: `utm_source` = канал, `utm_medium` = формат, `utm_campaign` = рубрика
или кампания, `utm_content` = id единицы контента. По каждой активности фиксируем: охват, вовлечение,
клики, DM, заявки на демо, регистрации, оплаты.

Кодовые слова для comment-to-DM: AGENT (RU) / SYSTEM (EN): автоматический DM со ссылкой на демо.
