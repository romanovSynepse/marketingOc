# Стек: что берём готовым, чтобы не терять время

Принцип: готовое и опенсорс там, где задача типовая. Сами пишем только то, что и есть продукт Syneps:
мозг, разбор паттернов, рерайт, оцифровку.

## Публикация и аналитика соцсетей
| Задача | Инструмент | Лицензия / цена | Комментарий |
|---|---|---|---|
| Автопостинг во все сети одним API | **Postiz** (gitroomhq/postiz-app) | AGPL-3.0, self-hosted | Threads, Instagram, TikTok, YouTube, LinkedIn, X, Telegram. Главный кандидат на замену ручного постинга |
| Альтернатива Postiz | Mixpost | MIT (Lite) | Проще, меньше сетей |
| Аналитика Instagram сейчас | Metricool | подписка | Уже подключён, данные в Traffic HQ |
| Threads | официальный Threads API | бесплатно | Реализован в `integrations/threads.py` |
| Comment-to-DM по кодовому слову | ManyChat | подписка, официальный партнёр Meta | Безопаснее, чем самописный бот |
| Веб-аналитика и воронка сайта | PostHog (self-hosted) или Umami | MIT | UTM → регистрация → оплата. Нужен доступ к syneps.ai |

## Глобал: аватары и голос (только с пометкой AI)
| Задача | Готовое | Опенсорс | Комментарий |
|---|---|---|---|
| AI-двойник Ника | HeyGen API | LatentSync, MuseTalk (lip-sync) | Для старта HeyGen: быстрее и качественнее. Опенсорс — когда объём вырастет |
| Голос Ника на EN | ElevenLabs | F5-TTS, XTTS-v2 | У весов F5-TTS и XTTS-v2 некоммерческие лицензии: для коммерции проверять или брать ElevenLabs |
