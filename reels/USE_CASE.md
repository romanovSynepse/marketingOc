## Клонировщик = перегенеровщик (что должно быть)
Один инструмент, три режима (методика `reels/klonirovshik.md` §4 + стиль `reels/stil-montazha.md`):
1. **Перемонтаж** (лёгкий): тот же ролик, невидимые отличия + новый хук + новая обложка. Без рамок, без цветовых сдвигов.
2. **Перегенерация исходника** (сильный): зеркало с новыми субтитрами; монтаж пересъёмки Ника по образцу оригинала; новый хук-кадр.
3. **AI-версия**: тот же сценарий, собранный AI (Hypit) — только после сметы и «да».
Плюс: проверка уникальности против всех прошлых версий, ротация исходников, реестр (`klonirovshik.md` §10).
**Порядок работы:** спросить сколько → превью 1 кадра хука + обложки → «ок» → рендер → проверка → «да» → Metricool.

## Стиль (из примеров Ника, 05.11)
- Хук: тонкий гротеск, нижний регистр, белый, без плашки, 2–3 строки по смыслу. **Два варианта раскладки:** слева сверху
  («14 дней / и 17 000$», «ии нашёл / идею, которая / залетит», «этот ролик / сделал не я») или по центру
  («10 месяцев / работы», «рилсы для бренда / за вечер»).
- Подпись под хуком — маркеры: `<< вот к чему пришёл`, `[ как это вышло ]`, `//. смотри как`, `* а ии`.
- Кадры: лицо крупно (селфи-ракурс) или экран ноутбука с интерфейсом SynOC (канвас с нодами). Обложка = кадр + хук, без рамки.
