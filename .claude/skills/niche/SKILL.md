# /niche — ниша → победители → разбор → сценарии

Первый шаг цикла Syneps: *найти, что работает → вытащить сценарий → переписать голосом бренда*.
Основа: инструкция `brain/synoc-marketer-instruction.md`, разделы 6 (контент, хуки, структуры),
7 (отбор и табу), 16 (тон), 22 (метрики вирусности). Перед работой перечитай разделы 6 и 7.

## Вход
`/niche <ниша> [для <бренд|блог Романов|Syneps>] [рынок: СНГ|США] [цель: охват|доверие|продажа]`.
Не указано → бренд = блог «Романов», рынок = СНГ, цель = охват. Не переспрашивай, а напиши, что взял по умолчанию.

## Правила
- Не выдумывать идеи от себя: каждый сценарий опирается на найденный ролик-прецедент (ссылка обязательна).
- Клонируем **структуру**, не чужой ролик: свои слова, свой кадр, своя подача. Чужое видео не скачиваем и не перезаливаем.
- Конкурентов Syneps в выдаче не рекомендуем; клиентов Syneps не упоминаем.
- Не отбирать авторов по расе, национальности, религии.
- Цифры — только из данных; пороги — «ориентир рынка».
- Бюджет vidIQ: поиск 5 кредитов, просмотр ролика 10. За один запуск — не больше ~80 кредитов без «да» Ника.

## Шаги
1. **Поиск.** `vidiq_instagram_tiktok_outlier_search`, 2–3 запроса с разными формулировками ниши
   (`embeddingType`: `concept`, плюс один `hook`), `resultsPerPlatform` 8–10, последние 30 дней.
   СНГ → `descriptionLanguage: ["ru"]`, `audienceQuery: "Culture/Region: Russia/CIS; Global: false; Demographics: …;"`.
   США → `["en"]`, `Culture/Region: USA`. Мало результатов → расширь до 60 дней или убери язык и отметь это.
2. **Отбор** (раздел 7 + 22). Оставь 5–7 роликов:
   - выше нормы автора ≥ 3× (outlier score), просмотры по таблице раздела 7;
   - репосты ≥ 10% от лайков или комментарии ≥ 1% — плюс; много лайков и почти нет репостов/комментов — реклама, выкинуть;
   - табу раздела 7 (харизма/внешность, танцы, маски, ситуативка, школьное, бренды на рекламе, чужой культурный контекст) — выкинуть;
   - один автор — один ролик; лицо в кадре в приоритете.
3. **Разбор.** Для 3–5 лучших — `vidiq_watch_shortform_content` (параллельно), опрос `vidiq_job_poll`.
   Для каждого: хук (текст + речь + кадр, 0–3 сек), структура по блокам, техника удержания, CTA,
   **почему сработало** (одна фраза), что переносится на бренд, а что нет.
4. **Сценарии.** 5 сценариев голосом бренда (раздел 16: без представлений, как с коллегой, без «магазина на диване»).
   Микс по воронке раздела 6: ~2 широких, ~2 прогрев/доверие, 1 продающий. Каждый:
   прецедент (ссылка) → рубрика и цель → 3 варианта хука → сценарий по секундам (текст в кадре / что говорим / что в кадре)
   → CTA с кодовым словом (Syneps: РИЛС, НИША, ДЕМО, ЗАВОД, СИСТЕМА) → формат производства (живое / гибрид / AI) → длина.
5. **Сохранить.** `reels/niche/<ниша-латиницей>_<ГГГГ-ММ-ДД>.md`: параметры запуска, таблица отобранных
   (ссылка, автор, просмотры, outlier, лайки/комменты/репосты, почему взяли), разборы, сценарии,
   отброшенное с причиной (кратко). Закоммить и запушь.
6. **Ответ Нику.** Коротко: сколько нашёл → сколько взял → топ-3 сценария одной строкой (хук + почему сработает)
   → путь к файлу → одно действие: «выбери номер, сделаю ТЗ на съёмку и суфлёр».
